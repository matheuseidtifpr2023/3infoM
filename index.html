Versionamento

O git é um software que permite realizar versões de um projeto.O github desktop é um software que faz a ligação entre VSC, Git e Github.

O github desktop permite fazer a sincronia entre o repositório local e o repositório remoto.

Commit

É o processo de confirmação de uma versão, ou seja, a cada operação é possível confirmar a operação.

Push

Este comando envia (sincroniza) as alterações realizadas no repositório local com o repositório remoto no git hub.
